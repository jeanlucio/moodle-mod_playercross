# 🧪 Automated Tests

PlayerCross ships with a PHPUnit test suite covering business logic, repository queries, web
services, and Privacy API compliance, plus a Behat suite covering the puzzle's gameplay, HUD
integration, and reports end-to-end in a real browser. Every CI push runs against the full
matrix (Moodle 4.5 → 5.x, PostgreSQL & MariaDB).

Most `event/*.php` classes aren't listed at all — Moodle only loads them lazily when the
corresponding event actually fires, so the instrumentation never sees them. `attempt_deleted`
is the one exception, since `attempts_history_service_test.php` genuinely constructs and fires
it: its 46% covers `init()` and `validate_data()` (exercised by every `create()`/`trigger()`
call), while `get_name()`, `get_description()` and `get_objectid_mapping()` stay uncovered —
they only run when actually rendering a log entry or mapping a restore, neither of which a
plain "the event carries the right objectid/relateduserid" assertion exercises.

`submit_final_guess` and `submit_term_guess` both reached 100% once their own
`roundresult_structure()`/`panel_structure()` branches picked up coverage from later test
additions — including the new ranking-summary fields and the attempts-remaining/
final-guess-exhaustion fields respectively. `ai_word_generator`'s own external AI-calling
methods (`call_ai()`, `call_core_ai()`, `generate_and_save()`...) are the one deliberate
gap left: covering them would mean mocking the actual `local_aihub`/`core_ai` HTTP calls,
judged not worth it for now.

`hud_service` carries a similar deliberate gap: `get_available_quantity()`, `get_item_name()`,
`consume_items()` and `grant_items()` each carry an `if (!self::is_installed())` guard clause
returning a neutral value — the fallback path for a site where `block_playerhud` was never
installed or has since been removed. Every dev and
CI environment for this plugin installs `block_playerhud` alongside it, so those four branches
are only exercised by `test_item_methods_return_neutral_values_when_not_installed()` on a site
that genuinely lacks the block; here it is skipped instead.
